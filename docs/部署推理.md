# FACTR 部署推理

## 启动策略服务

终端 1：

```bash
cd /root/autodl-tmp/FACTR
conda activate factr

python serve_policy.py \
  --host 0.0.0.0 \
  --port 5555 \
  --checkpoint /root/autodl-tmp/FACTR/checkpoints/flip_box_force \
  --device cuda:0 \
  --dtype float16 \
  --warmup 1
```

## 运行 Mock Client

终端 2：

```bash
cd /root/autodl-tmp/FACTR
conda activate factr

python mock_client.py \
  --host 127.0.0.1 \
  --port 5555 \
  --model factr \
  --count 2 \
  --codec-test \
  --reset-first \
  --image-mode gradient \
  --task "Stand the box upright."
```
