# FACTR 部署推理

## 启动策略服务

终端 1：

```bash
cd /root/autodl-tmp/FACTR
conda activate factr

python serve_policy.py \
  --host 0.0.0.0 \
  --port 5555 \
  --checkpoint /root/autodl-tmp/FACTR/checkpoints/_smoke_insert_plug_force \
  --device cuda:0 \
  --dtype float16 \
  --warmup 1
```
